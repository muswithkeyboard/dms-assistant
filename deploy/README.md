# Выкладка на сервер

Ассистент и Caddy в Docker. Caddy сам получает и продлевает сертификат HTTPS (Let's Encrypt). Модель и платные
ключи не нужны: ответ строит код по документам. Документы договоров в репозиторий не входят, их передают отдельным
архивом `dms-data.tar.gz`.

## Что нужно

- Linux-сервер от 2 ГБ памяти (лучше 4 ГБ) и ~3 ГБ свободного диска; процессор любой (x86_64 или ARM).
- Docker Engine и плагин compose: https://docs.docker.com/engine/install/ (проверка: `docker compose version`).
- Домен, A-запись которого указывает на IP сервера. Открытые входящие порты 80 и 443.
- Архив данных `dms-data.tar.gz` (комплект документов и энкодер) — передаётся отдельно, не через GitHub.

## Установка

```bash
git clone https://github.com/muswithkeyboard/dms-assistant.git
cd dms-assistant
bash deploy/install.sh dms.example.ru ~/dms-data.tar.gz
```

Скрипт:
1. распакует архив в `data/`;
2. соберёт образ;
3. разберёт комплект в базу. Это занимает несколько минут, пик памяти около 0,6 ГБ;
4. запустит сервис и Caddy.

В конце скрипт напишет адрес сайта. При первом заходе на `https://<домен>` выпускается сертификат, это 10–30 секунд.

## Обновление

```bash
cd dms-assistant
git pull
bash deploy/install.sh
```

Домен берётся из `deploy/.env`. База, чаты и подключённые клиенты сохраняются: они лежат в томах Docker.
Новый архив данных передаётся вторым аргументом: `bash deploy/install.sh <домен> <архив>`. Тогда комплект
импортируется заново.

## Обслуживание

| Что | Команда (из папки `dms-assistant`) |
|---|---|
| журнал | `docker compose -f deploy/docker-compose.server.yml logs -f` |
| остановить | `docker compose -f deploy/docker-compose.server.yml down` |
| запустить | `docker compose -f deploy/docker-compose.server.yml up -d` |
| состояние | `docker compose -f deploy/docker-compose.server.yml ps` |

Настройки — в `deploy/.env` (образец — `deploy/.env.example`): лимит памяти `DMS_MEM_LIMIT`, кэш пунктов
`DMS_CLAUSE_CACHE_MAX`, папка данных `DMS_DATA_HOME`. После правки выполните `bash deploy/install.sh`.

## Если не работает

- **Сертификат не выпускается.** Проверьте, что A-запись домена указывает на сервер, а порты 80 и 443 открыты
  в файрволе и у хостера. Подробности — в `logs caddy`.
- **403 «Недопустимый адрес».** Сайт открыт не по домену из `deploy/.env`. Ассистент отвечает только на свой домен.
- **В списке договоров пусто.** Импорт не прошёл: смотрите вывод скрипта или запустите заново с архивом.
- **Мало памяти.** Не ставьте `DMS_MEM_LIMIT` выше реальной памяти сервера. При 2 ГБ не держите на сервере
  другие тяжёлые сервисы.
