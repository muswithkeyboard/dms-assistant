# ADR 0020. Тестовые документы договоров комплекта — в git

Принято 30.10.2026 по решению пользователя: «докинь в гит страховые документы, они тестовые».

## Решение
1. Обезличенные документы договоров комплекта (`Кейсы_обезличенные/Документы`: ГК 1–3, 13 договоров, 34 файла,
   18 МБ) лежат в репозитории в `kit/Документы/` и входят в публичную копию.
2. Не входят по-прежнему: кейсы `Кейсы_К10-К19_обезличенные.xlsx`, эталоны (`gold/`), производные базы
   (`data/derived/`), материалы `reference/`, ТЗ.
3. `deploy/install.sh` копирует `kit/Документы/` в `data/raw/Кейсы_обезличенные/Документы` и запускает импорт, когда
   документы изменились. Архив данных стал необязательным: в нём только энкодер rubert-tiny2
   (`dms-encoder.tar.gz`). Без энкодера маршрутизация вопросов работает на правилах (ADR 0009).
4. Проверка гигиены в `scripts/verify.sh` допускает документы в `tests/fixtures/` и `kit/`. Образ Docker `kit/`
   не содержит (`.dockerignore`): документы монтируются томом, как раньше.

## Почему
Коллега выкладывает сервис на сервер из GitHub. Документы в репозитории убирают отдельную передачу архива.
Кроме того, имя папки `Кейсы_обезличенные` в архиве с macOS было записано в форме NFD, и на Linux код его не находил.
Имена в git записаны в NFC (`core.precomposeunicode`), поэтому через git эта проблема не возникает.

## Последствия
Правило 4 в `docs/rules.md` дополнено исключением. При обновлении комплекта новые документы кладутся в `kit/Документы/`
и в `data/raw/`.
