# ADR 0004. Добавление клиники: процесс ТЗ ред. 2, ветку определяет ответ СК

Принято 23.10.2026 по уточнению кейсодателя; **переписано 23.10.2026 по ТЗ ред. 2, п. 5.2.2** (заменяет прежнюю
схему «письмо в СК сразу»).

## Решение — конечный автомат запроса (`scenarios/add_clinic.py`)

| Состояние | Действие системы | Черновик | Переход |
|---|---|---|---|
| `alt_found` — подходящая клиника в программе есть | Предложить одну или несколько: клиника/филиал, адрес, основания, ограничения (франшиза, условия доступа), источники | — | — |
| `not_in_program` — нужной клиники нет | Сообщить, показать альтернативы; если клиника есть в другой программе договора — сказать это, **но не считать доступной** | HR: клиники нет, альтернативы, можно запросить добавление | кнопка «HR хочет добавить» |
| `hr_wants_add` | Сформировать запрос | Письмо в СК о добавлении | → `awaiting_insurer` |
| `awaiting_insurer` | Ждать: менеджер фиксирует ответ СК (кнопки «бесплатно» / «платно» + вставка текста ответа как источник) | — | `insurer_free` / `insurer_paid` |
| `insurer_free` | Отметить клинику добавленной (только в запросе, не в документах договора) | HR «клиника добавлена» | закрыть |
| `insurer_paid` | Запросить согласование у HR | HR: повторный запрос с условиями СК (цитатой из ответа) | «HR согласен» → подтверждение в СК + HR «добавлена»; «HR отказал» → закрыть |
| `insufficient` — не хватает программы, клиники или вида обращения | Уточнить или показать неизвестный статус | не формируется | — |

## Правила

- Переходы — только по действию пользователя; информационный вопрос автоматизацию не запускает (FR 09).
- Повторный запуск не добавляет клинику второй раз и ничего не отправляет (идемпотентность по `request_id + clinic`).
- Черновик сохраняется в запросе, редактируется, копируется; не отправляется автоматически. Содержит тему,
  обращение, юрлицо и договор, программу, клинику, вид обращения, суть. Неизвестные обязательные поля — «[ЗАПОЛНИТЬ]».
  Без диагнозов, персональных данных, согласований, сроков, обещаний покрытия; клиника не «добавлена» до
  подтверждения СК.
- Ветку определяет только ответ СК; подсказки из документов — контекст со ссылкой, не решение.
