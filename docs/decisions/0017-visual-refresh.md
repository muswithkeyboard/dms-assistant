# ADR 0017. Облегчённый визуал: тёмная тема со скруглениями, иконки MAINS, ASCII-арт, подпись Justmedit

Принято 29.10.2026 по запросу пользователя: «сделай интерфейс более лёгким: чёрно-золотой выглядит тяжело
и устаревше, бело-зелёный пусто и скучно», «возьми иконки с сайта mainsgroup», «используй арты ASCII в тему»,
«можно сделать нашу надпись Justmedit».

## Решение
1. **Тёмная тема (Mains) — мягче.** Графит вместо чистого чёрного (`--bg #111214`, `--surface #18191C`,
   `--surface-2 #1F2024`, линии `#2C2E33`), тёплый белый текст `#F2F0EA`, золото светлее и только акцентом
   (`--primary #CDB178`). Углы больше не прямые: радиусы те же, что в светлой (карточка 18 px, контрол 12 px,
   пузыри асимметричные). Активный пункт шапки — полупрозрачная золотая подложка, а не заливка.
   Это меняет правило `docs/ui_style.md` «у Mains углы прямые».
2. **Светлая тема («Кубики») — живее.** Фон с лёгкой зелёной и жёлтой подсветкой (`--page-glow`), шапка —
   градиент тёмно-зелёного (`--brand-grad`), активный пункт шапки — белая плашка, карточки с мягкой тенью
   (`--shadow-card`).
3. **Иконки MAINS.** Семь линейных иконок с mainsgroup.ru (`app/themes/mains/assets/icons/`: doctor, building,
   person, money, chart, laptop, pie) лежат в `static/icons/` и выводятся маской: цвет — токен `--icon-fill`
   (зелёный в светлой, золотой градиент в тёмной). Где: приветствие чата, карточки примеров (иконка по основам слов
   вопроса — `ui.yaml chat.example_icons`), список чатов (группа — здание, договор — человек), дерево документов,
   «О прототипе». Иконки — собственность MAINS, взяты для прототипа по их кейсу; **в публичный репозиторий без
   разрешения MAINS не публиковать** (при публикации исключить `static/icons/`).
4. **ASCII-арт.** Свои рисунки из символов (сгенерированы скриптом, не чужие изображения): «сгусток» для приветствия
   чата и «волна» для «О прототипа», по варианту на тему (`static/art/*-light.webp`, `*-dark.webp`, 40–125 КБ),
   выбор — токены `--art-hero`, `--art-band` (с 29.10.2026 — щит с крестом и линия пульса, `shield-*`, `pulse-*`). Декоративны (`aria-hidden`), на узком экране приглушены.
5. **Подпись команды.** Слева вверху вместо пустого квадрата — словесный знак «Justmedit» (первая буква — акцент
   темы `--icon-accent`), за ним — «Ассистент ДМС»; «Сделано командой Justmedit» в подвале и на «О прототипе».
   Тексты — `ui.yaml` (`team`, `footer.team`, `pages.about_*`).
6. **«О прототипе»** — вместо одного абзаца: вводный текст, шесть карточек «что умеет прототип» с иконками, подпись
   команды.

## Последствия
- Все цвета, радиусы, тени, арт — только токенами тем; блок `@media (prefers-color-scheme: dark)` повторяет
  тёмную тему (тест `test_dark_media_block_matches_dark_theme`); контраст ключевых пар — тест `test_contrast.py`.
- Метка ответа («Можно при условиях» и др.) — плашкой цвета метки со значком: статус по-прежнему «иконка + слово».
- Логика ответов не менялась.
