# ADR 0015. Модель-помощник: понять вопрос своими словами, не решать за документы

Принято 27.10.2026 по просьбе пользователя: «подключи всё же простенький ИИ, чтобы было проще общаться, например
чтобы он лучше понимал мои присланные вопросы и более гибко отвечал».

## Решение
1. Модель — локальная qwen3:1.7b через Ollama (OpenAI-совместимый адрес, провайдер `openai_compat`), без ключей и
   без отправки документов наружу. Режим «размышлений» выключен (`DMS_LLM_REASONING=none`): ответ меньше секунды на
   CPU Mac вместо десятков секунд. Режим движка остаётся `guided` (`DMS_LLM_SMALL=1`): вывод, метку и ссылки строит
   код по документам (ADR 0009, `docs/rules.md` п. 1–2).
2. `assist.rephrase` — единственная задача модели: сообщение менеджера своими словами → один вопрос в стандартном
   виде («к лору сходить, это бесплатно?» → «Входит ли приём оториноларинголога в программу?»). Вызывается, только
   когда правила маршрутизации вопрос не поняли (общий сценарий или нет ни услуги, ни вида помощи, ни клиники), и
   берётся, только если маршрут стал лучше и не потерял клинику, программу и договор исходного вопроса. В ответе
   менеджер видит, как понят вопрос (`ChatReply.understood`).
3. Проверка кодом: в переписанном вопросе нет чисел и «названий» не из вопроса; каждая лемма — из вопроса, служебных
   слов стандартных вопросов (`route_markers.yaml assist_words`) или равнозначных словам вопроса слов словарей
   (вид помощи и его синонимы, глаголы и синонимы процедур, `assist_synonyms`). Подмена услуги словом словаря, не
   связанным со словами вопроса, отбрасывается: на «а зубы лечить будут?» модель предложила «удаление зуба», и без этой
   проверки ответ стал ложным «нельзя».
4. Обычные реплики («привет», «спасибо», «что ты умеешь») — ответ из `reply.yaml smalltalk`, без модели.

## Отвергнуто
- Пересказ первой фразы ответа моделью («гибче отвечал»): на замере qwen3:1.7b либо копировала фразу, либо меняла
  смысл («Недостаточно данных» → «Можно при условиях»). Фраза ответа остаётся шаблоном кода.
- Заполнение слотов моделью (`DMS_GUIDED_LLM_SLOTS`, ADR 0009): выдумывала слоты в 10 из 57 вопросов.

## Последствия
- Без Ollama (или при сбое) помощник молчит — работает как прежде, на правилах. `DMS_LLM_ASSIST=0` — выключить.
- Тесты не читают `.env` разработчика (`tests/helpers.py`): проверка не зависит от локальной модели; помощник
  проверяется заглушкой модели (`tests/guided/test_assist.py`).
- Docker: `DMS_LLM_BASE_URL=http://host.docker.internal:11434/v1`; на сервере 2–4 ГБ модель 1.7b занимает ~1,4 ГБ.
