# ADR 0014. Ответ в виде сообщения чата: коротко, что сказано в договоре, что уточнить

Принято 27.10.2026 по замечанию пользователя: «интерфейс сильно проще — сейчас ничего не понятно; ответ даёт неясные
ссылки на документы, а словами ничего не пишет; резюмируй находки словами, чтобы это был именно чат».

## Решение
1. `Answer.reply: ChatReply` собирает КОД (compose) из уже проверенных утверждений (verify) — без модели:
   - `lead` — прямой ответ одной-двумя фразами по метке и сценарию (шаблоны `config/texts_ru/reply.yaml`): «Да,
     входит — …», «Нет: … исключение», «Зависит от: …», «По документам ответа нет: …»; для отказа — «Отказ может быть
     обоснован, если …» из разбора отказа;
   - `points` — «Что сказано в договоре»: до `REPLY_POINTS_MAX` пунктов; у каждого — формулировка кода и ТОЧНАЯ
     цитата документа (часть проверенной цитаты, ≤ `REPLY_QUOTE_CHARS`, по границе фразы), сноска на источник; без
     кодов строк (`c06.program#t5r250`) и служебных слов; утверждения «по этому пункту» заменяются содержанием
     пункта (цитатой);
   - `ask` — что уточнить (из missing/questions, без дублей), `caution` — одна строка ограничений и допущений.
2. Интерфейс чата: сообщение пользователя справа, ответ ассистента слева — `lead`, «Что сказано в договоре»
   (пункты со сносками [n]), «Что уточнить»; сноска открывает источник (документ → пункт → цитата) во всплывающей
   панели; служебное (контекст, все утверждения, таблица альтернатив, технические id, режимы) — под «Подробнее»;
   выбор клиники — компактный блок в сообщении; метка — одна понятная строка («Нужно уточнить», «Входит», «Не
   входит», «Входит при условиях»).
3. Правила `docs/rules.md` не меняются: каждое утверждение `points` — с проверенной ссылкой; без ссылки на экран не
   попадает; метки — по config/verdict_rules.yaml.

## Следствия
- Менеджер читает ответ, а не разбирает документы; источники — по клику.
- Модель (если будет ключ) может переписать `lead` и формулировки `points` — только из тех же утверждений и цитат
  (следующий шаг, не в этом этапе).
