# ADR 0018. Исправления по внешнему ревью 29.10.2026: импорт, ошибки расчёта, загрузка документа

Принято 29.10.2026. Коллега прислал ревью бэкенда и функционала сайта (по публичной копии и демо-режиму); пункты
сверены с текущим кодом, подтверждённые — исправлены по решению пользователя («Да, исправляй»).

## Решение
1. **Импорт из интерфейса — атомарно, как CLI.** `Service.start_import` собирает базу в `<kit.sqlite>.tmp` (прежняя
   база — `previous` для договоров клиентов), затем `KitStore.replace_file` под блокировкой хранилища: сброс WAL,
   `os.replace`, новое соединение в том же объекте. Пока идёт сборка, ответы читают прежнюю базу целиком; сбой —
   прежняя база цела. Индексы поиска и кэши перечня сбрасываются по договорам старой и новой базы. `default_store()`
   больше не запоминает пустое хранилище в памяти навсегда; на чистой установке импорт создаёт `kit.sqlite`.
   Хранилище в памяти, переданное явно (тесты), импортируется как раньше.
2. **«Договор не загружен» — только по делу.** `ContractNotLoaded(KeyError)` в `KitStore`; сервис проверяет договоры
   контекста до расчёта (`engine.contracts_of`) и ловит только этот класс. Другая `KeyError` из движка — 500
   «внутренняя ошибка» и запись в журнал с файлом и строкой (без текста исключения).
3. **Вопрос не остаётся без ответа.** Сбой расчёта после записи вопроса дописывает ответ ассистента с текстом
   ошибки — выбор клиники и уточнения ищут предыдущий вопрос и не берут «висящий».
4. **Один расчёт на обращение.** `prepare_message` помечает обращение занятым до конца потока расчёта; второй вопрос
   в то же обращение — 409 `request_busy` («Ассистент ещё отвечает…»). Предел «один тяжёлый расчёт на адрес»
   (HeavyGate) — как был, для разных обращений.
5. **Загрузка документа на «Документах» участвует в ответах.** Файл договора после проверки разбирается на пункты
   (`attachment.parse_file`) и дописывается к документам договора (`KitStore.add_documents`, как документ из чата
   по ADR 0016), статус «Готов». Файл группы без договора — только сохраняется, с подсказкой загрузить его в договор.
   Повторный импорт комплекта такой документ стирает (как и документы из чата) — это сказано в предупреждении.
6. **Сайт.** Пример вопроса подписан договором («Откроет чат: Договор № 1…»), открывает чат своего договора и ставит
   вопрос в поле ввода — отправляет менеджер. Импорт комплекта — после подтверждения. У каждого ответа — «Скопировать
   ответ»: вывод, пункты с цитатами и источниками, что уточнить.
7. Мёртвый код: `security.current_client` (никем не ставился; все вызовы HeavyGate передают адрес явно) и
   `RateLimiter.release` удалены.

## Не исправлено (в отчёте этапа)
Остальные подтверждённые пункты ревью — архитектура и эксплуатация (общий дедлайн ответа, пул соединений SQLite,
миграции `KitStore`, разделение `service.py`, CI, вход и роли, удаление чатов и клиентов, справочник клиник) —
больше дня работы каждый; перечислены в `docs/status/stage-w20-review.md`.
