# ADR 0005. Изоляция договоров: условия одного договора не переносятся на другой

Принято 23.10.2026 по уточнению кейсодателя («ИИ сильно запрещено что-то придумывать, переносить условия одного
договора на другой»).

## Решение

Изоляция обеспечивается кодом, а не промптом:

1. Индекс разделён по договорам. Поиск принимает ровно один `contract_id` и не видит чужих фрагментов.
2. В модель на одну оценку уходят фрагменты только одного договора.
3. `citations.verify` выбрасывает ссылку на фрагмент другого договора и считает её в метрике «попытки переноса».
4. `compose.py` не смешивает в одном утверждении ссылки разных договоров.
5. Контекст «вся группа»: если договор застрахованного не определён — вопрос «какой договор/юрлицо?»; если вопрос
   общий («где входит стоматология?») — отдельный блок ответа по каждому договору с его ссылками, без обобщений.
6. Нет ответа в документах договора → «в документах договора не указано» с перечнем просмотренного и черновиком
   вопроса в СК. Ни «обычно», ни «как правило».

## Проверка

Ловушки в синтетике: одноимённые программы «Стандарт» в двух договорах с разной стоматологией, лимитами
и клиниками; эталоны задают одинаковые вопросы в обоих. Ворота: 0 показанных ссылок и утверждений из другого
договора; в сравнении моделей — доля попыток переноса до фильтра.
