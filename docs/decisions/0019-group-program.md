# ADR 0019. Чат группы компаний с выбранной программой — только договоры с этой программой

Принято 29.10.2026 по замечанию пользователя: «я выбрал программу застрахованного при старте нового чата, но модель
всё равно спросила программу».

## Решение
`engine.contracts_of` (замороженный файл, правка автора): в контексте ГК с заданной программой берутся только
договоры группы, в карточке которых есть программа с этим названием (сравнение без регистра и лишних пробелов).
Застрахованный с этой программой — сотрудник этих юрлиц: спрашивать программу по остальным договорам незачем.
Программы нет ни в одном договоре группы — все договоры, как раньше (программа уточнится в ответе). Контекст «договор»
не меняется. Изоляция договоров (ADR 0005) сохраняется: ответ по-прежнему по каждому договору отдельно.

## Последствия
- Вопрос «Какая программа у застрахованного?» по договорам без выбранной программы больше не задаётся.
- Наборы ревизии: метки по оставшимся договорам те же, ложных «можно»/«нельзя» — 0. В review8 8 пар «вопрос × договор»
  (r8-186…r8-190: ГК 1 «Рязань Стандарт» → договоры № 1 и № 4; ГК 3 «Стандарт» → № 9–11; «Бизнес» → без № 11) больше
  не отвечаются: в этих договорах выбранной программы нет; разметка набора исходила из всех договоров группы.

## Дополнение (аудит уточнений, 29.10.2026)
- Вопрос «Какое юрлицо / договор?» (required_facts `context_is_group`) не задаётся, если программа чата есть ровно в
  одном договоре ГК (`scenarios/clarify.py`).
- Программа задана, но у договора её нет: `engine` передаёт в разбор слот `program_not_found` (вторая правка
  автора в `engine.py`), вопрос — «Программы «X» в этом договоре нет. Какая программа у застрахованного?».
- Окно нового чата не создаёт чат с программой, которой нет ни в договоре, ни в группе (подсказка выбрать из списка);
  регистр названия приводится к названию из договора.
- Аудит 8 наборов (1 995 вопросов, контекст из разметки): заданную программу ассистент переспрашивает только там, где её
  нет в договоре (2 вопроса, с явной формулировкой); повторов вопроса о договоре нет; одинаковые вопросы по договорам ГК
  склеивает интерфейс. Метки до и после — те же.
