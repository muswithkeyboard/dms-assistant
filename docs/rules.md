# Правила проекта

Номера пунктов совпадают со ссылками в комментариях кода и документах.

0. Условия одного договора на другой не переносятся никогда (ADR 0005): все инструменты принимают `contract_id`;
   контекст «ГК» — отдельный проход по каждому договору. Ветку «бесплатно/платно» определяет ответ СК (ADR 0004).
0а. Источник текста docx — собственный разбор с `numbering.xml` (автонумерация Word): сторонние конвертеры теряют
   номера пунктов. Каталог клиник СК и общие правила СК — не условия договора.
1. Ответ только по документам выбранного контекста. Каждый существенный вывод — ссылка «документ → пункт → фрагмент»,
   прошедшая `citations.verify`. Непроверенная ссылка выбрасывается; утверждение без ссылки на экран не попадает.
2. Нет обязательного факта → уточняющий вопрос. Противоречие документов → показать оба фрагмента. Знания модели
   «как обычно бывает в ДМС» в выводы не попадают.
3. Сервер писем не отправляет: в `src/` нет SMTP и почтовых API. Менеджер отправляет сам («Скопировать»,
   «Скачать .txt», «Открыть в почте»). Письмо — шаблон из конфига, подставляются только сущности; фильтр
   `config/forbidden_promises.yaml` — тест на шаблонах и страховка на итоговом тексте.
3а. «Нет в документах» и «не нашли» — разные вещи. `absent` только при загруженном и разобранном документе нужного
   типа; `covered=not_found` никогда не даёт метку «нельзя».
4. Документы клиентов и всё производное от них в репозиторий не попадают (`data/` вне git). Исключение —
   обезличенные тестовые документы договоров в `kit/Документы/` (ADR 0020). В git — код, конфиги,
   свои маленькие тестовые файлы. В логах нет текстов документов, обращений, ключей.
5. Конфигурация — только в `config/`: правила вердиктов, ветки, приоритет документов, обязательные факты, тексты,
   промпты. Логику выводов в коде не зашивать.
6. LLM — только через `src/dms_core/llm/`, провайдер — из `.env`. Тесты работают без сети на `mock` с кассетами.
   Без ключа — режим ответа кодом (guided).
9. Тесты — функции `test_*` с `assert`; тестам, которым нужна модель или документы клиента, без них ставится SKIP.
10. Алгоритмы выводов комментируются по-русски: что проверяется, по какому правилу конфига, откуда источник.
11. Интерфейс — только через токены цветов, без CDN и внешних ресурсов, статус «иконка + слово», ошибки по-русски.
