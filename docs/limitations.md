# Ограничения, что не сделано, риски

ТЗ п. 10.3. Состояние на 26.10.2026 (коммит 3837d51). Что поддержано — `docs/scenarios.md`, цифры —
`docs/test_report.md`.

## Ответы без модели (режим guided)

- По умолчанию модели нет: ответ строит код по сценарию (ADR 0009). Свободные вопросы вне четырёх сценариев дают
  «нужно уточнение» или найденные пункты договора без вывода.
- Метка SC 01 консервативна: при любом недоказанном шаге — «недостаточно данных». На эталонах без клика менеджера
  метка совпала в 7 из 35 кейсов, обязательные ссылки найдены 21 из 184; ложных «можно» и «нельзя» — 0.
- «Можно» и «нет в перечне» по клинике — только после выбора клиники менеджером из перечня (ADR 0010). Без клика —
  «недостаточно данных, выберите клинику».
- Числа из вопроса («6-й приём», «20 км») не сравниваются с лимитами программы: лимит показывается как условие.
- Поиск по пунктам — BM25 с морфологией и синонимами видов помощи; векторного поиска по документам нет.
- Утверждение без проверенной ссылки не показывается: ответ бывает короче эталонного.
- `demo_saved` (сохранённый ответ примера с живой модели) включается, только если есть файл
  `data/app/demo_saved/<id>.json`; таких файлов нет.

## Документы

- В комплекте нет части документов, на которые ссылаются договоры: у СОГАЗ (ГК 3) — Прил. 1 (Правила ДМС), Прил. 3,
  Прил. 5, Прил. 7.1–7.6, Прил. 8; у Зетты (ГК 1) — Прил. 1 (Правила ДМС), Прил. 1.1, Прил. 1.1б. Система называет их
  «не предоставлены» и не делает выводов о том, что в них могло быть.
- Каталог «ЛПУ_Регионы Стандарт.xlsx» и правила НС — не условия договора, в ответах не участвуют.
- PDF без текстового слоя (сканы) не читаются: OCR нет.
- Смысл кодов Ренессанса в перечне (КБ+/КБ0, П8-МВ/П8-КВ) в документах не расшифрован — коды хранятся, но не
  толкуются.
- Файл, загруженный на вкладке «Документы», в поиск не попадает (статус останавливается на «Полнота проверена»).
  Чтобы документ участвовал в ответах, его загружают через «Подключение клиента» (ADR 0011).
- Допсоглашений в комплекте нет, их разбор не проверен.

## Подключение клиента и неизвестная СК

- Известные СК (Зетта, Ренессанс, СОГАЗ) разбираются адаптерами. Неизвестная СК без разметки — только поиск по
  пунктам договора (readiness `limited`), метки «недостаточно данных».
- После разметки перечня оператором (ADR 0012) работают клиники, выбор клиники и «нет в перечне». Матрица
  «программа × вид помощи» по разметке (ADR 0013) **не реализована** (этап w10 в работе): у неизвестной СК нет
  «можно» по виду помощи, договор остаётся `limited`.
- Изменить «не распознавать формат» и название СК после создания договора нельзя (нет PATCH договора).
- Подключение обрабатывает один договор за раз; импорт комплекта — самый тяжёлый момент по памяти (пик 613 МБ).

## Сервис

- Нет входа и ролей: оператор и менеджер — один пользователь; разделения клиентов между собой нет (вне объёма
  прототипа, ADR 0011). Сервис рассчитан на 127.0.0.1 или закрытую сеть.
- Письма не отправляются: только черновики («Скопировать», «Скачать .txt», «Открыть в почте» по клику).
- Подготовку ответа нельзя отменить: закрытие вкладки обрывает поток SSE, но расчёт идёт до конца.
- Шрифт интерфейса — временный IBM Plex Sans (Onest не скачан, шрифтов заказчика нет).
- Шкала оценки ответа 1–5 с комментарием — наше допущение (в ТЗ п. 9 «согласуется»).

## Риски

- **Личность клиники.** Сопоставление названия из свободного текста остаётся главным источником ошибок; защита —
  клик менеджера (ADR 0010). Неверный клик менеджера даст неверную метку.
- **Неверная разметка оператором.** Ложное «можно» возможно через неверно размеченную таблицу; защита — проверка
  содержимого (`mapping_suspicious`), пробный разбор, строка без вида помощи не подтверждает клинику.
- **Новые формулировки вопросов.** Каждая ревизия на новом наборе находила новые классы ошибок; правила
  маршрутизации и покрытия подобраны на наборах ревизий, их полнота на реальном потоке обращений неизвестна.
- **Порог kNN** подобран на тех же 57 вопросах, на которых измерен (0,81) — оценка завышена.
- **Неполнота комплекта.** Выводы, зависящие от непредоставленных Правил ДМС, система не делает — на таких
  вопросах будет «недостаточно данных».
